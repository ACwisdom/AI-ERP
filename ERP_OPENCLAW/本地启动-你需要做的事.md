## 安装依赖与启动（Python 3.11 装好后执行）

在 **ERP_OPENCLAW** 目录：

```powershell
cd D:\AI+ERP\ERP_OPENCLAW

# 安装依赖（requirements.txt 第 2 行本地路径可能报错，可忽略该行后安装其余包）
py -3.11 -m pip install -r requirements.txt
# 若失败，用 readme.txt 中的核心包列表分批安装

# 终端 1：MCP
$env:PYTHONPATH="D:\AI+ERP\ERP_OPENCLAW\src"
py -3.11 -m mcp_server.server_main

# 终端 2：FastAPI 后端
$env:PYTHONPATH="D:\AI+ERP\ERP_OPENCLAW\src"
py -3.11 -m uvicorn api_view.web_main:app --reload --host 0.0.0.0 --port 8090

# 终端 3：前端（若未开）
cd frontend
npm run dev
```

**验证：**

- http://localhost:8090/docs 能打开
- 终端出现 `DeepAgent Chat API 启动成功!`
- 前端发消息后 Network 里 `/api/chat/stream` 为 200
